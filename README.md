## 🎯 About NOVA LIST

Most productivity apps feel like digital paperwork.

You create tasks.

You complete tasks.

Nothing feels rewarding.

**NOVA LIST** changes that.

Inspired by RPG progression systems, NOVA LIST transforms daily productivity into a game where every completed quest earns rewards, every focus session grants progress, and every achievement pushes you closer to becoming a legendary warrior.

---

## ⚡ Core Features

| Feature | Description |
|----------|------------|
| ⚔️ Quest System | Create and manage tasks like RPG quests |
| 🪙 Gold Economy | Earn gold for completing quests |
| 🏆 Level Progression | Unlock higher ranks as you grow |
| ⏳ Focus Timer | 25-minute Pomodoro-inspired focus sessions |
| 💾 Local Storage | Progress automatically saved |
| 📱 Responsive UI | Works on desktop and mobile |
