## 🎯 About The Project

Most productivity apps feel like digital notebooks.

I wanted something different.

**NOVA LIST** transforms productivity into a game-like experience where every task becomes a quest, every completed challenge earns rewards, and every focus session helps you level up.

Instead of simply checking boxes, users progress through a complete RPG-inspired productivity system with quests, gold, levels, and focus rewards.

## ✨ Features

### ⚔️ Quest Management
- Add custom quests instantly
- Track active quests
- Complete quests with a single click
- Move completed quests automatically

### 🪙 Reward System
- Earn Gold for completing quests
- Earn Gold for successful focus sessions
- Lose Gold when deleting completed quests
- Real-time reward tracking

### 🏆 RPG Leveling System
Progress through multiple ranks:

| Level | Rank |
|---------|---------|
| 1 | Recruit |
| 2 | Novice |
| 3 | Apprentice |
| 4 | Squire |
| 5 | Journeyman |
| 6 | Fighter |
| 7 | Veteran |
| 8 | Expert |
| 9 | Champion |
| 10 | Warrior |

### ⏳ Focus Mode
- Built-in 25-minute focus timer
- Pomodoro-style workflow
- Reward on successful completion
- Instant reset functionality

### 💾 Persistent Storage
- Saves quests automatically
- Saves completed tasks
- Saves Gold balance
- Saves level progress
- Uses browser Local Storage

### 📱 Responsive Design
- Desktop Friendly
- Mobile Friendly
- Clean Dark UI
- Modern Dashboard Layout

## 🎮 Gameplay Mechanics

### Completing Quests

```text
Quest Completed
       ↓
+50 Gold Earned
       ↓
Level Progress Updated
       ↓
Quest Moved To Completed Section
```

### Focus Session

```text
Start Focus
      ↓
25 Minute Session
      ↓
Session Complete
      ↓
+50 Gold Reward
```

## 🧠 Why I Built This

I was tired of boring to-do apps.

Most productivity tools felt repetitive and uninspiring.

So I decided to combine productivity with RPG-style progression and create a system where users feel rewarded for completing meaningful work.

NOVA LIST was built to make productivity feel engaging, rewarding, and fun.
